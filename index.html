How Asset VFS Works

A background process creates a virtual folder where every asset is a text file in T3D format. The agent works with them like regular files.

1

Mount

VFS creates a folder with two sections: meta/ (fast metadata) and content/ (full content).

→
2

Read

Agent opens a .t3d file — VFS fetches data from the running editor and returns text.

→
3

Write

Agent saves modified text — VFS automatically applies changes in the editor.

Структура VFS

Виртуальная папка повторяет структуру проекта. Каждый .uasset → .t3d текстовый файл.

C:\Users\You\AppData\Local\AssetVFS\MyProject\
meta/                            # метаданные (быстро, без IPC к редактору)
  Characters/
    DA_Hero.t3d                  # класс, зависимости, теги
  Items/Weapons/
    DA_Weapon_IronSword.t3d
content/                         # полное содержимое (чтение + запись)
  Characters/
    DA_Hero.t3d                  # все свойства ассета как текст
  Items/Weapons/
    DA_Weapon_IronSword.t3d

meta/ — мгновенный доступ, кеш из AssetRegistry. content/ — полный экспорт, данные загружаются из редактора при первом обращении.

VFS Structure

The virtual folder mirrors your project structure. Each .uasset → .t3d text file.

C:\Users\You\AppData\Local\AssetVFS\MyProject\
meta/                            # metadata (fast, no editor IPC)
  Characters/
    DA_Hero.t3d                  # class, dependencies, tags
  Items/Weapons/
    DA_Weapon_IronSword.t3d
content/                         # full content (read + write)
  Characters/
    DA_Hero.t3d                  # all asset properties as text
  Items/Weapons/
    DA_Weapon_IronSword.t3d

meta/ — instant access, cached from AssetRegistry. content/ — full export, data is fetched from the editor on first access.

Работает и без агента

Asset VFS — это обычная папка на диске. Вы можете открывать .t3d файлы в любом текстовом редакторе, искать по ним grep-ом, или писать собственные скрипты для автоматизации. Агент не обязателен — это просто самый удобный способ.

Works without an agent too

Asset VFS is just a regular folder on disk. You can open .t3d files in any text editor, search them with grep, or write your own scripts for automation. An agent isn't required — it's just the most convenient way.

Частые вопросы

Нужен ли запущенный Unreal Editor?
Да, для чтения полного содержимого (content/) и для записи. Метаданные (meta/) работают с кешем.
Это безопасно?
Да. Все изменения применяются через стандартные механизмы редактора — так же, как ручное редактирование. Рекомендуется использовать Git.
С какими агентами работает?
С любыми, которые поддерживают MCP (Model Context Protocol): Claude Code, Cursor, и другие. Также работает как обычная файловая система для скриптов.
Работает на Mac или Linux?
Нет. Asset VFS использует Windows Projected File System (ProjFS) — только Windows 10/11.
Какие версии UE?
Unreal Engine 5.x. Нужен включённый плагин Python Editor Script (включён по умолчанию).
Замедляет ли редактор?
Нет. VFS работает в отдельном процессе и обращается к редактору только при чтении или записи файла.
Что такое T3D?
Встроенный текстовый формат UE для описания объектов. Тот же формат используется при копировании через буфер обмена в редакторе.

FAQ

Does the Unreal Editor need to be running?
Yes, for reading full content (content/) and writing. Metadata (meta/) works from cache.
Is it safe?
Yes. All changes go through standard editor mechanisms — same as manual editing. We recommend using Git.
Which agents does it work with?
Any agent supporting MCP (Model Context Protocol): Claude Code, Cursor, and others. Also works as a regular filesystem for scripts.
Does it work on Mac or Linux?
No. Asset VFS uses Windows Projected File System (ProjFS) — Windows 10/11 only.
Which UE versions?
Unreal Engine 5.x. Requires the Python Editor Script plugin (enabled by default).
Does it slow down the editor?
No. VFS runs in a separate process and only contacts the editor when reading or writing a file.
What is T3D?
UE's built-in text format for describing objects. The same format used when copying via clipboard in the editor.

Инструкция по установке

1. Включите ProjFS (PowerShell от админа):

Enable-WindowsOptionalFeature -Online -FeatureName Client-ProjFS -NoRestart

2. Установите .NET 8: winget install Microsoft.DotNet.Runtime.8

3. Соберите провайдер: cd Scripts/AssetVFS/ProjFSProvider && dotnet build -c Release

4. Добавьте MCP-сервер в .mcp.json проекта.

5. Откройте UE Editor, вызовите asset_status — VFS запустится.

Installation guide

1. Enable ProjFS (PowerShell as admin):

Enable-WindowsOptionalFeature -Online -FeatureName Client-ProjFS -NoRestart

2. Install .NET 8: winget install Microsoft.DotNet.Runtime.8

3. Build provider: cd Scripts/AssetVFS/ProjFSProvider && dotnet build -c Release
